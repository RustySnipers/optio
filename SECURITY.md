Security Policy
Optio is critical infrastructure software for network intelligence and agent deployment. We take security seriously and appreciate responsible disclosure.

Supported Versions
Version	Supported
0.1.x	✅ Yes
< 0.1	❌ No
Reporting a Vulnerability
Please report security issues privately and responsibly.

Email: security@optio.dev
PGP: (placeholder — provide public key and fingerprint here)

Include the following details in your report:

A clear description of the vulnerability

Steps to reproduce (or a proof-of-concept)

Affected versions or commits

Potential impact (e.g., data exposure, RCE, privilege escalation)

Any relevant logs, screenshots, or crash reports

Do not open a public GitHub issue for sensitive security bugs.
Public disclosure should happen only after we have reviewed and addressed the issue.

Response Timeline
Acknowledgement: within 48 hours

Target fix timeline: within 14 days, depending on severity and complexity

We will keep you updated throughout the process.

Out of Scope
The following are generally not considered vulnerabilities:

Social engineering or phishing of staff or users

Denial of service from high-volume traffic without a specific exploit

Spam or unsolicited contact

Issues in third-party services not controlled by Optio

Reports without a reproducible security impact

Thank you for helping keep Optio secure.
